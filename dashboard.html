The Banker's Rounding vs. Indian Half-Up Rounding Proof

Python's built-in round() uses Banker's Rounding (round-half-to-even), where round(0.5) = 0 and round(1.5) = 2. Indian financial accounting standards strictly mandate Half-Up Rounding (ROUND_HALF_UP).

# Anchor Transaction Case Study (₹1,337.49 @ 200 bps MDR):
Gross Amount = 133,749 paise (₹1,337.49)
Platform Fee = 133,749 × 200 / 10,000 = 2,674.98 paise → 2,675 paise (₹26.75)
18% GST Base = 2,675 × 1,800 / 10,000 = 481.50 paise
❌ Banker's Rounding (even): 481.50 → 481 paise (₹4.81)
✅ Ledgerscope Half-Up: 481.50 → 482 paise (₹4.82) [MATCHED TO THE EXACT PAISE]
